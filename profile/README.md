# Okwu — African Language Commons

Open, community-governed resources for African-language machine translation:
a validated parallel corpus, the validation toolkit and review process behind it,
an evaluation suite, and the governance that keeps it maintained.

This is an ecosystem, not a single dataset. It is under active establishment.
